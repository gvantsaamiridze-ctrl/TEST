## გამოქვეყნება GitHub Pages-ზე
1. შექმენით რეპოზიტორია `TEST` და ატვირთეთ `index.html` (ან `git push`).
2. Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `(root)`.
3. საიტი: https://<username>.github.io/TEST/
